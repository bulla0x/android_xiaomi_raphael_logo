# Raphael Logo Creator

## How to use

1. Prepare four images, one for each screen:
   - `error.bmp`
   - `fastboot.bmp`
   - `lock.bmp`
   - `unlock.bmp`
2. Put all four images and `raphael_logo.py` together in **one folder**.
3. Open a terminal in that folder and run:

   ```bash
   py raphael_logo.py
   ```

4. The script generates a new custom `logo.img`.
5. Flash it to your device using custom recovery or fastboot and enjoy your new splash logo.

## Warnings

1. Raphael's screen resolution is **1080x2340**, so all images must be exactly this resolution.
2. All image files must be in **BMP** format.
3. Try to keep image file sizes small.
4. I am not responsible for any damage to your device. You know what you are doing.
